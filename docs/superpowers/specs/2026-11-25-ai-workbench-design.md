# AI 工作台 (AI Workbench) 设计方案与规范

## 1. 概述与目标

在 openNook 展开界面的顶部 Tab 栏中（紧邻「文件暂存」图标右侧），新增一个独立的 **AI 工作台**（`ai-workbench`）原生 Tab 入口。点击后无缝切换进入专属的多 Agent 实时任务与工作台画布，完整还原活动 AI 会话样式，支持 Claude Code、Codex、Gemini CLI 等本地智能体的状态监控、进度追踪与终端/IDE 一键跳转。

---

## 2. 架构设计 (Approach A: Native Island Tab + Shipped Mod)

### 2.1 顶部 Tab 栏扩展 (`crates/nook/src/island.rs`)
- **位置**：紧邻 `file-shelf/tab` 右侧，处于 Tab 序列的固定快捷入口区。
- **图标**：24x24 紧凑 Squircle，带有精致的 `bot`（或 `sparkle`）矢量图标，选中态与 hover 态样式与 `file-shelf/tab` 严格保持一致。
- **导航联动**：点击触发 `s.select("ai-workbench")`，平滑滑动切入 AI 工作台视图。

### 2.2 工作台模块 (`crates/nook/mods/ai-workbench/`)
- `mod.json`：注册模块元数据（标题“AI 工作台”，图标“bot”）。
- `main.js`：继承 `nook/ui` 的 `View` 类，实现 `expanded()` 画布与会话列表渲染。
- `icon.svg` / 资源：各 Agent 专属品牌矢量图标（Claude 火花、Codex 机器人、Gemini 晶体钻石、快捷指令/事件总线图标）。

### 2.3 数据源与交互链路
1. **真实会话监控**：
   - 调用 `agents()` 获取已接入 openNook 的本地智能体进程（进程 PID、工作目录 cwd、当前任务名、运行状态等）。
   - 联动 `codexStatus()` 与 `mapStatus()` 捕获最新的模型推理轮次、已完成任务与事件流。
   - 辅助后台定时器通过 `exec` 扫描本地 Claude Code、Codex、Gemini CLI 活跃进程与最近修改文件。
2. **模拟/演示兜底（Fallback Mode）**：
   - 当本地暂无活动智能体任务时，自动加载高品质预置演示任务流（即设计图中的 6 个典型场景），保证任何时刻点开都美观且可演示。
3. **情境交互动作**：
   - 点击「跳转 ↗」按钮：执行 `run("agents.focus", { pid })` 或 AppleScript 将对应 Agent 的终端/VSCode 窗口置顶聚焦。
   - 点击「授予终端权限」：向对应进程发送授权指令或快速打开对应终端。
   - 卡片整体点击：支持展开任务日志或详细文件 diff。

## 3. UI 视觉规范与组件结构

### 3.1 容器与卡片基底
- **画布宽度**：自适应展开灵动岛（`pageWidth - 32px`），垂直滚动容器，带滚动条与平滑滑动。
- **卡片样式**：单条高度约 54px，间距 6px，圆角 10px。
  - 背景：深黑微渐变（`#14151a` ~ `#121317`）。
  - 边框：`1px #23252d`（hover 时升温为 `#32353f`）。
  - 内边距：`px(10).py(8)`。

### 3.2 卡片左侧两段式信息结构
1. **品牌 Squircle 头像**（32x32，圆角 8px）：
   - **Claude Code**：暗赤色底 `#2a1814` + 橙红火花图标 `#e06c45`。
   - **Codex**：暗深蓝底 `#142034` + 纯蓝机器人图标 `#388bfd`。
   - **Gemini CLI**：暗晶紫底 `#181e38` + 亮晶蓝钻石图标 `#7c9bf8`。
   - **音频/总线工具**：暗灰底 `#1e2028` + 对应特性符号。
2. **第一行（任务标题 + 状态药丸）**：
   - 标题格式：`[Agent 品牌] · [当前主任务]`（10.5px，白色 `#ffffff`，加粗）。
   - 伴随药丸状态：
     - `● 待处理输入`：琥珀橙色点与边框（`#ff9f0a`，底色 `#2b1d0c`）。
     - `● 运行中`：高亮电蓝/绿点（`#64d2ff` / `#30d158`，带 pulse 呼吸动效）。
     - `🔒 待确认权限`：橙红警示胶囊（`#ff9f0a`）。
     - `✓ 已完成`：纯净浅绿徽标（`#30d158`）。
     - `● 就绪/闲置`：沉稳灰度胶囊（`#8e8e93`）。
3. **第二行（元数据与时间戳）**：
   - 格式：`● [当前工作文件路径] · [模型代号] · [相对更新时间]`。
   - 字体：8.5px，字色 `#8e8e93`，路径自动截断（truncate）。

### 3.3 卡片右侧动态交互区
- **待处理输入**：展示 `[>] 确认 N 个文件修改` + `刚刚` + 突出高亮的电蓝主按钮「**跳转 ↗**」（高度 20px，圆角 pill，字号 8.5px，hover 变亮）。
- **待确认权限**：展示橙色操作药丸按钮「**[✓] 授予终端权限**」+ `时间` + `>`。
- **运行中**：展示测试进度 `● 执行单元测试 [4/7]` 或截图对比 `[|] 分析截图 diff 88%` + `时间` + `>`。
- **已完成 / 闲置**：展示产出摘要 `PR #142 已生成` 或 `0 高危风险 · 待命` + `时间` + `>`。

## 4. 实施计划与步骤

1. **资源与图标准备**：添加 `sparkle.svg`（Claude 火花图标）与 `gem.svg`（Gemini 晶体图标）至 `crates/nook/assets/icons/`。
2. **Tab 栏原生集成**：在 `crates/nook/src/island.rs` 中为 `ai-workbench` 添加原生 Tab 按键，并在选中判断中支持该模块。
3. **工作台 Mod 开发**：在 `crates/nook/mods/ai-workbench/` 中创建 `mod.json` 与 `main.js`，实现列表与真实/演示数据桥接。
4. **验证与编译交付**：通过 `opennook check` 验证模块，使用 `scripts/bundle.sh release` 打包并安装重启 openNook。
